# StickyED Updater

**https://edmondyang81.github.io/stickyed-updater/**

Browser tool for a reTerminal Sticky running StickyED: installs the bundled firmware,
writes the Hermes settings to the SD card and copies books, all over USB.
Use desktop Chrome or Edge.

Nothing private lives here: settings you type are sent straight to the device over USB.
`firmware.js` is generated from the (private) StickyED repo by `scripts/make_sticky_tool.py`.
Offline alternative: `python3 start.py`, then open http://localhost:8471.
